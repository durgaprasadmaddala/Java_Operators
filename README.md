 # Java Operators

Java operators are special symbols used to perform operations on values and variables. They are the building blocks used to calculate results, compare values, assign data, and make logical decisions in Java programs.
1. Arithmetic OperatorsUsed to perform standard mathematical calculations.+ (Addition / String Concatenation)- (Subtraction)* (Multiplication)/ (Division)% (Modulus - returns the division remainder)2. Assignment OperatorsUsed to assign values to variables. They include the simple assignment as well as shortcuts called compound assignments.= (Simple assignment)+=, -=, *=, /=, %= (Compound assignments; e.g., x += 5 is equivalent to x = x + 5)3. Unary OperatorsOperators that require only a single operand to perform actions like incrementing, decrementing, or negating a value.++ (Increment by 1 - can be used as prefix ++x or postfix x++)-- (Decrement by 1 - can be used as prefix --x or postfix x--)- (Unary minus - negates a positive value)! (Logical complement - inverts a boolean value)4. Relational / Comparison OperatorsUsed to compare two values and always return a boolean result (true or false).== (Equal to)!= (Not equal to)> (Greater than)< (Less than)>= (Greater than or equal to)<= (Less than or equal to)5. Logical OperatorsUsed to combine multiple boolean expressions or alter logical states, primarily for decision-making.&& (Logical AND - returns true if both conditions are true)|| (Logical OR - returns true if at least one condition is true)! (Logical NOT - reverses the boolean state)6. Ternary OperatorA shorthand version of the if-else statement. It is the only operator in Java that takes three operands.Syntax: condition ? expression_if_true : expression_if_false;7. Bitwise and Shift OperatorsOperate directly on the individual bits of integer data types (like int and long).& (Bitwise AND)| (Bitwise OR)^ (Bitwise XOR)~ (Bitwise Complement / NOT)<< (Signed left shift)>> (Signed right shift)>>> (Unsigned right shift - fills vacant spaces with zeros)8. Type Comparison Operatorinstanceof (Compares an object reference against a specified class or interface type).
